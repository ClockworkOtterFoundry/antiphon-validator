What this checks — and what it doesn’t (yet)
  • XML well-formedness, then the full Schematron business rules of the detected format: the CEN EN 16931 rules plus the Peppol or XRechnung (KoSIT) layer where applicable.
  • The XSD schema layer is not run in this version. Schematron catches most real-world rejections, but a schema-invalid document can produce confusing rule results.
  • Factur-X/ZUGFeRD: paste the invoice XML. Extracting the XML from the PDF container is coming; PDF files are not read yet.
  • Validated against the pinned official rule releases listed below — the same artifacts the national platforms use.
Privacy

Validation runs entirely in your browser (via the vendored SaxonJS runtime — see license). The document you paste or open is never sent anywhere: no upload, no storage. You can verify this — open your browser’s network tab and validate.

The hosted version may report anonymous usage counts to help us prioritize: which format was validated, pass or fail, and which rule IDs fired — never any document content, no cookies, no identifiers. If you join the waitlist, we store the email you give us and nothing else.

Antiphon — the mandate calls; the response follows in the prescribed form. A native .NET SDK for EN 16931 validation and generation is in the works.
